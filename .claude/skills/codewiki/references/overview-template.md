# 仓库总览模板

在所有模块文档完成后生成 `overview.md`。仓库总览用于建立导航和系统级理解，不替代模块文档。

## 推荐结构

```markdown
# 仓库名称

## 项目概述

说明仓库用途、主要用户、系统边界和核心能力。

## 系统架构

使用顶层模块和外部系统展示端到端架构。

## 核心模块

概括每个顶层模块，并链接其文档。

## 关键流程

描述最重要的端到端数据流或控制流。

## 入口与外部依赖

说明主要运行入口、接口、存储和外部服务。

## 文档导航

列出顶层模块文档。
```

## 生成规则

- 架构图以顶层模块和外部系统为节点。
- 每个顶层模块必须有且只有一个主要导航链接。
- 只概括模块职责，不复制模块文档细节。
- 根据源码和分析结果描述项目，不使用宣传性或推测性表述。
- 若仓库没有模块树，直接从组件索引和仓库结构提炼高层架构。
- 明确记录分析过程中跳过或无法解析的核心区域。
